# BlackviewActive5

Набор ADB-скриптов и списков пакетов для дебloat'а и управления смартфоном **Blackview Active 5** без root'а. Скрипты рассчитаны на запуск с хоста под **FreeBSD** (пакет `android-tools-adb`), но одинаково работают на Linux/macOS/Windows — везде, где есть рабочий `adb`.

## Возможности

- Удаление ненужных предустановленных приложений (`pm uninstall --user 0`, без модификации прошивки — приложение можно вернуть)
- Массовая установка APK из папки одной командой
- Блокировка фоновой активности для выбранных приложений через `appops`
- Готовые списки установленных пакетов (все / системные / пользовательские, с путями и без)
- Быстрая настройка Wi-Fi и энергосберегающих параметров после сброса устройства

## Требования

- Рабочий `adb` в `PATH`
  - FreeBSD: `pkg install android-tools-adb`
- Включённая на телефоне отладка по USB (Настройки → Для разработчиков → Отладка по USB)
- Разрешённый доступ ПК на самом телефоне (диалог подтверждения при первом подключении)

Проверить подключение:

```sh
adb devices
```

## Структура репозитория

| Файл | Назначение |
|---|---|
| `remove.sh` | Удаляет заранее заданный список не нужных предустановленных пакетов (Blackview-утилиты, часть Google-приложений) через `pm uninstall --user 0` |
| `uninstall_apk.sh` | Удаляет пакеты построчно из файла `list_for_remove` |
| `list_for_remove` | Список package name для `uninstall_apk.sh` |
| `install_apks.sh` | Устанавливает все `.apk` из указанной папки: `./install_apks.sh /path/to/apk_folder` |
| `apk_store` | Папка/заготовка для APK, устанавливаемых через `install_apks.sh` |
| `block_background.sh` | Отключает фоновую активность (`RUN_IN_BACKGROUND`, `RUN_ANY_IN_BACKGROUND`) для списка сторонних приложений |
| `set_pass_wifi.sh` | Подключение к Wi-Fi, включение режима энергосбережения и отключение Google Play Services — **используйте как шаблон**, см. предупреждение ниже |
| `git.sh` | Вспомогательный скрипт для работы с репозиторием |
| `all_apps.txt` / `all_apps_nopath.txt` | Список всех установленных пакетов (с путём к APK / только имена) |
| `system_apps.txt` / `system_apps_nopath.txt` | Список системных пакетов |
| `user_apps.txt` / `user_apps_nopath.txt` | Список пользовательских пакетов |
| `info_full` / `info_build_id` | Полная информация об устройстве / build id |
| `note` | Рабочие заметки — разбор предустановленных пакетов Blackview/Unisoc/Google по категориям (безопасно отключать / осторожно / не трогать) с готовыми командами `pm disable-user` |

## Быстрый старт

```sh
git clone https://github.com/definitly486/BlackviewActive5.git
cd BlackviewActive5
chmod +x *.sh

# посмотреть, что стоит на устройстве
adb shell pm list packages -f > all_apps.txt

# убрать заготовленный список лишних приложений
./remove.sh

# заблокировать фоновую активность у выбранных приложений
./block_background.sh

# поставить набор APK из папки
./install_apks.sh ./apk_store
```

Откат удаления одного пакета:

```sh
adb shell cmd package install-existing <package.name>
```

## ⚠️ Важно

- `remove.sh` использует `pm uninstall --user 0` — приложение скрывается для текущего пользователя, но не удаляется из прошивки, и его всегда можно вернуть командой выше.
- Прежде чем отключать системные пакеты (`com.android.providers.*`, `com.google.android.gms`, `NetworkStack`, `Telephony`, оверлеи и т.д.), сверьтесь со списком «не трогать» в `note` — их отключение может сломать сеть или интерфейс.
- **`set_pass_wifi.sh` содержит захардкоженные учётные данные Wi-Fi и не подходит для использования «как есть».** Перед публикацией/использованием вынесите SSID и пароль в переменные окружения или аргументы скрипта, чтобы не светить реальные креды в публичном репозитории.
- Действия выполняются на свой страх и риск — авторы не несут ответственности за возможную неработоспособность устройства.
